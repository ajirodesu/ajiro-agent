# Q/R/S/X. UI Integration + Preservation

## Protection summary (X, §§69–74 — NON-NEGOTIABLE, honored)
Zero redesigns performed in this build: no layout/spacing/typography/color/
icon/navigation/animation changes; composer, user/assistant messages,
Markdown, tool cards, thinking treatment, terminal presentation, permission
drawer all structurally untouched. New code connects behind existing
controllers (backend-first, §71): permission engine behind the approval
setting/drawer; broker behind exec checks + terminal `run`; modes behind the
existing agent picker/drawer (data, not visuals); terminal tabs/clear/A±/
search added as functional controls in the existing visual language (§47
explicitly requires these functions).

skills/plugins → android_local/Linux. Adapters (permission store, broker

output); canonical model distinguishes code segments for the renderer.
